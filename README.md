OrientApp es una aplicación móvil diseñada para ayudarte a descubrir cual especialidad técnica
se adapta mejor a tu perfil académico y tus intereses personales. Mediante el análisis de tus
notas y un test vocacional asistido por Inteligencia Artificial, la app te orientara hacia una de las
cuatro especialidades disponibles.
